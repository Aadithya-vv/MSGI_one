# Bundled geographic data

ne_110m_land.geojson: Natural Earth 1:110m land polygons, public domain.
Source (downloaded November 13, 2026):
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
License/terms: https://www.naturalearthdata.com/about/terms-of-use/

Natural Earth places its raster and vector map data in the public domain; credit
is optional. MSGI One displays credit. The coarse global land layer is bundled
for offline geographic context and contains no member locations. Member markers
come exclusively from authorized server queries over coarse city catalog centroids.
