## A. 90-second elevator pitch

“A student looking for a mentor often does not know which graduate to approach.
Alumni may want to help but lack a clear channel. Institutions need a trusted
way to keep those relationships alive.

MSGI One brings students, alumni and staff into one institutional networking
experience. A student can discover relevant alumni, understand why a mentor is
recommended, explore opportunities and see the community across cities. Alumni
can share expertise, respond to connections and create career or project openings.
Staff can explore the institutional network without automatically receiving
administrator powers.

Our recommendation logic is explainable: it compares skills, career domains,
mentoring availability and interests. These are relevance points, not AI prediction
confidence or a guarantee of mentorship.

Today we are showing a working offline demonstration using clearly fictional
profiles. Separately, we have implemented and tested authenticated onboarding,
privacy controls and protected database workflows. The development backend has
reviewed schema and MSEC reference catalogs; institutional administration and
production email still have approval gates.

Our next step is a supervised, college-owned pilot with approved verification,
support and credential custody. MSGI One: One Community. Infinite Connections.”

This is a rehearsal script, not a timed recording. Aim for natural speech and
trim to the organizer's confirmed speaking limit.

## D. Offline fallback

  and airplane mode enabled. Do not attempt hosted signup or recovery.
- Projection failure: demonstrate on the approved device and narrate; use local
  screenshots for a larger view when available. Mirroring compatibility is pending.
- App interruption: reopen MSGI One; saved role and simulated changes restore.
  Return Home before switching roles. Reset only with the presenter's consent.
- Device failure: use the captured signed-APK screenshots under
  `build/task12a/signed-apk/`. Explain that they show an executed offline demo.
  Do not pretend screenshots are a live backend session.
- A stale or missing account is irrelevant to this demo. Never bypass verification
  or change backend settings to rescue the presentation.

## E. Judge Q&A

| Question | Evidence-based answer |
| --- | --- |
| Is this a trained AI system? | No. Mentor discovery uses deterministic weighted relevance: skills 40%, domain 30%, availability 20%, interests 10%. Missing evidence is handled explicitly; explanations show the actual comparable signals. |
| What does 100/100 mean? | Full comparable evidence aligns under these rules. It is not success probability, AI confidence or guaranteed availability. Sparse evidence is capped; availability alone does not earn a high score. |
| Are these real MSEC graduates? | No. All displayed people, employers and affiliations are explicitly fictional. The supplied programme catalog is separate reference information. |
| Does it work offline? | The frozen demo does. Real account authentication and community queries require a separately configured, authorized backend and internet. |
| Can Staff approve members? | No. A declared Staff role is not a protected administrator grant. Administration is separately implemented/tested locally and is not activated in this demo. |
| How is privacy enforced? | Real backend workflows use protected membership/role records, RLS and restricted RPC outputs; location design is city-level and consent-based. The demo uses isolated local simulation repositories. |
| Is the backend deployed? | The last reviewed development checkpoint has eleven migrations and 51 reference records. The twelfth administration migration is pending. Production SMTP, administrators and public rollout are not approved. |
| How was it tested? | Task 12A ran 197 Flutter tests and analyzer/format checks, plus signed-APK offline acceptance. Local database/API security evidence is documented separately; do not present older tests as fresh runs. |
| Can this support thousands of users now? | No production capacity claim is established. Local 5,000-entry admin queue measurements were about 2.4 seconds/page; optimization and controlled load testing remain necessary. |
| Who owns and operates it? | College ownership, verification authority, support, privacy policy and credential/signing custody require institutional acceptance. This package prepares that handover; it does not claim completion. |
| What is the rollout plan? | Approve policies and operators, verify backup/recovery, review the pending deployment separately, activate a consented email pilot, then accept a small supervised onboarding trial. |

If asked about an untested feature, say what exists, what was tested and what
remains pending. AI-assisted engineering is part of the development method; any
