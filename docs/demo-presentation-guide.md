# MSGI One presentation guide

Run flutter run -d emulator-5554 without backend defines. Choose Explore Demo.
MSEC catalogue names use supplied institutional information. All people, affiliations, relationships and opportunities are fictional. The
persistent Demo indicator and About simulated data menu explain this. No demo
workflow registers accounts, sends email or writes to Supabase.

1. Student: Mira Rao. Search alumni, view a profile, send a simulated
   request, inspect mentor reasons, browse internships and explore the offline map.
2. Alumni: Arjun Iyer. Use the header perspective selector, view the profile,
   accept an incoming request, change mentoring availability and create a simulated
   opportunity. Switch back to see consistent relationships and career listings.
3. Staff: Kavya Sen. Explore students/alumni, profiles, mentors and careers.
   This perspective has no administrator capabilities.

Local changes survive app restarts. Before presenting again, use Demo controls,
Reset demo and confirm. Exit demo returns to the entry screen. Real community
access separately requires configured Supabase, authentication and verification.
Do not put real personal information in demonstration fields.

Screenshots: build/task08/screenshots/.
Debug APK: build/app/outputs/flutter-apk/app-debug.apk (not production signed).


MSEC academic walkthrough: open Profile, Edit demo profile and select a degree
programme for a student/alumni perspective. Discovery, Filter alumni, Degree
programmes uses the same catalog IDs. Science and Humanities is an academic
department, not a degree. The Demo information action explains that these are
fictional affiliations, not actual MSEC graduates/staff or college endorsements.
Mentor/profile and opportunity detail Back returns to the originating page.
